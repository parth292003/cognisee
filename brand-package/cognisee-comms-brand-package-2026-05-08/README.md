# Cognisee Comms Brand Package

Prepared: 2026-05-08

This package contains the current Cognisee May 2026 visual identity assets for comms, press, decks, and lightweight web/social use.

## Contents

- `01-logos/current/` - current preferred Cognisee logo exports.
- `01-logos/reference/` - reference lockups from the current website/source files.
- `02-color/` - palette guide, CSS variables, JSON tokens, and a simple preview.
- `03-fonts/` - font files, web import CSS, and source links.
- `04-usage/` - logo usage notes and a paste-ready email note.

## Current Public Site

- Canonical site: https://www.cognisee.ai
- Apex domain: https://cognisee.ai redirects to `www.cognisee.ai`
- Vercel project: `cognisee-landing-may2026`

## Important Notes

- Preferred logo: horizontal symbol plus wordmark.
- Preferred dark background: deep green-black, not pure black.
- Preferred light background: milky green-cream, not white.
- Primary display font: Newsreader.
- Body font: IBM Plex Sans.
- Mono/meta font: IBM Plex Mono.

The current logo source available here is raster PNG. I included high-resolution transparent PNG exports and preview lockups, but this package does not include a native vector wordmark source.
