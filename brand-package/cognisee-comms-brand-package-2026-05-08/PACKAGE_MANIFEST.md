## Limitations

- No native vector source for the horizontal Cognisee wordmark was available in the project files. The package uses transparent high-resolution PNG exports from the current website source logo.
- Older triangle/pyramid Cognisee marks were intentionally excluded from the current logo set to avoid mixing identities.
